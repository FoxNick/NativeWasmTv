# 小米 6 Android 7.1.1：HEVC Main10 实播验证

设备：`ff0316c7`，Xiaomi MI 6，MSM8998，Android 7.1.1 / API 25。
使用设备现有 `xiao.bu.tv` 1.7.0（versionCode 7，ARM32，安装时间 2026-09-17 11:39:56），自动解码模式；未安装 APK 或测试组件、未清除应用数据。

## 结论及直接证据

这台设备可以在本 App 中硬解本次测试的 **1920×1080、25fps、HEVC Main10 / 10bit** 视频。不能将这个结论推广到所有 Android 7.1.1 设备或所有 4K60 / Dolby Vision 视频。

同一杜比 Channel Identification 视频的 HLS/fMP4 与 MP4 均有以下日志：

```text
Video: hevc ..., yuv420p10le(tv), 1920x1080
onSelectCodec: mime=video/hevc, profile=2, level=123
VideoCodec: MediaCodec, OMX.qcom.video.decoder.hevc
```

- `yuv420p10le` 确认实际输入为 10bit，HEVC profile 2 为 Main10。
- IJK 的实际 `VideoCodec: MediaCodec` 日志，以及系统实例化 `OMX.qcom.video.decoder.hevc`，共同确认实际采用高通硬解；没有仅使用 App 配置态的 `decoder=hardware` 作为证据。
- HLS 实播输出约 25fps，播放至约 75.23 秒后正常停止；源时长约 75.56 秒。期间有短暂 HLS 缓冲，因此不声称网络播放完全无停顿。
- MP4 同样成功启用高通 HEVC 硬解，播放至约 75.23 秒正常停止；播放中采样输出 24.2–25.8fps，中位数 25fps。HLS 播放中采样 25–25.8fps，中位数 25fps。两者截图显示画面正常。
- 未进行人工听感验证，也未测试 1080p60、4K60、HDR 显示或 Dolby Vision。
