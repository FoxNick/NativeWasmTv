# WebView 未提交改动检查（2026-09-24）

本轮未执行 Git 暂存或提交，保留已有工作区改动。重点人工检查浏览器工具栏、标签生命周期、请求拦截、用户脚本及管理网页；其他播放相关改动运行现有回归，不代表全部工作区已经完成逐行审计。

## 已修复

- 地址行及主页、前进、后退按钮移除。更多固定在收藏栏右侧，刷新、收藏当前页保留在菜单；收藏栏隐藏后更多移到标签栏右侧。
- `onLoadResource` 中用户脚本的补注入次数与 UA 伪装共用计数器：native UA 下计数不增长，导致每个资源重复传输整段脚本。改为独立、最多三次的补注入计数。
- 恢复后台标签时重复创建策略管理器，旧 document-start 注册无法移除。现在管理器随 WebView 实例保留，销毁时释放；更改加载策略后后台标签保留历史、重新加载，避免继续使用旧脚本/WebRTC 设置。
- 拦截线程读取 WebView URL 和可变标签状态。改为 UI 线程发布请求策略及主文档 URL 快照；广告过滤先于资源嗅探，后台保留标签也执行广告过滤。
- 用户脚本与内置策略原来拼成同一编译单元，一个语法错误会使整段失效。现在分别注册/执行，并按源码摘要实现每文档去重。
- 修复 `@match` 的通配子域名不包含根域名、域名边界及 `@exclude-match` 语义；配置未变时不再反复解析和编译脚本。
- 广告数据库更新与缓存回填存在竞争，首次安装还可能短暂缓存 NONE。数据库代次、规则元数据及缓存失效协同更新，旧查询不得回填新代缓存。
- 域名引擎不再将带请求类型/站点限制的规则或例外误解释为全局规则；不支持的限定规则保守跳过。更新失败增加冷却时间，MD5 响应增加大小上限，数据库查询异常不阻断正常请求。
- 自定义广告规则改用不可变快照，避免所有资源请求竞争全局锁。
- 标题/URL 更新不再重建收藏栏，无变化不重写固定标签配置；图标磁盘写入串行且队列有上限，避免同一临时文件并发写，内存图标缓存限制为 128 项。
- 脚本列表无变化时不重建 DOM；导入/保存期间防止切换编辑目标；重复导入更新同一条目，保留停用状态；满 32 条时仍可更新已有脚本。
- 关闭标签的 `withEndAction` 在 Android 4.0.x 不存在，旧系统改为直接关闭。异步右键探测结果在切换页面后丢弃。

## 验证与范围

- arm32 / arm64 debug APK 编译通过。
- Android 模拟器 `BrowserPolicyInstrumentation` 通过：两行工具栏、更多可达、保留标签策略实例、补注入上限、脚本错误隔离/匹配/去重、广告规则及缓存更新。
- 广告匹配热缓存 100,000 次查询在该模拟器约 25 ms；这是单项测量，不代表整页加载提速比例。
- 9 个 Node 测试文件通过，其中管理页覆盖 51 个场景。
- 5 个 Python 回归脚本通过（播放进度、断线恢复、HLS 响应、10-bit 能力、轨道切换）。
- 全项目 Android Lint 尚未通过：第三方转码等模块仍有大量 API 兼容和其他错误。没有通过关闭检查或修改最低系统版本来掩盖这些问题。
- 本轮没有 Android 4.0.4 真机或手机/电视双设备联测；旧系统运行效果和各站点脚本兼容性仍需设备验证。不提供 GM_* / @require API，也不保证任意第三方脚本可用。
