# Android 4.4.4 插件下载实测

设备：三星 SM-G3608，Android 4.4.4，armeabi-v7a / armv7-perf。每轮通过 ADB 清除 xiao.bu.tv 全部数据后启动，恢复默认 gh-proxy.org 加速；共 3 轮，均成功。仅原 App 增加计时日志，未安装测试组件。
