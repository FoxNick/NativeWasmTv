# 收藏与媒体控制修复（2026-09-25）

## 修改

- 收藏栏导入的频道文件夹内，`webview://` 网页走新标签回调；普通网页收藏和嵌套收藏夹保持新标签行为。音视频频道仍交给原频道播放流程。
- 32 个标签全部固定、无法新增时只提示上限，不再回退为覆盖当前页。
- 手机媒体控制器的封面区域原来固定为 `67.5vh`，浏览器工具栏占用空间后挤出播放按钮并被父容器裁切。改为按容器剩余高度伸缩，优先保留进度和播放控制空间。
- 管理页下载按钮对有明确时长的 HTTP(S) 媒体文件直接触发同源下载；MP4、MP3、M4A、FLAC 等扩展名，以及播放器已识别的无扩展名直链均支持。无限时长电台、HLS 保留录制页。
- 新下载接口仅接受当前播放会话的 sourceKey，不接受任意下载 URL。切台后拒绝旧会话；主线程只采集当前状态，网络读取和 64 KiB 分块转发在服务线程执行，不整文件载入内存。
- 下载保留播放请求的 Referer/User-Agent/Origin，Cookie/Authorization 不跨重定向源转发；支持单段 Range/If-Range、Unicode 文件名和接收端代理。上游中断后关闭连接，不在二进制文件后追加错误响应。
- 媒体页面 CSS/JS 资源版本更新，避免浏览器继续使用旧布局。

## 验证

- arm32 / arm64 debug APK 构建通过；9 个 Node 测试文件通过（管理页 52 个场景）。
- Android 9 模拟器 MediaDownloadInstrumentation：完整 512 KiB 文件和 Range 分段内容逐字节一致；鉴权头、签名参数、If-Range、文件名、中断响应、过期会话、文件/直播分类通过。
- RemoteMediaRoutingInstrumentation：真实 IJK 播放无扩展名 MP3，播放状态暴露下载能力，管理接口返回与原 MP3 完全一致的文件。
- BrowserPolicyInstrumentation：点击导入文件夹网页新增标签且保留原页；全固定标签容量保护通过，同时已有脚本/广告缓存回归通过。
- Playwright/Chromium 检查 384×854、360×740、390×844、320×568、854×384，模拟手机浏览器工具栏压缩可视高度，直播和有限文件共 10 组：播放按钮未被裁切、未被遮挡且可点击。384×854/可用高度 676 时按钮底边为 583，容器底边为 598。
- 浏览器检查使用本地页面和模拟媒体状态；没有实测截图所用手机浏览器或手机/电视双设备下载。浏览器最终下载提示的样式由手机浏览器决定。

本轮未提交代码，保留了工作区原有修改；不宣称全项目 Android Lint 已通过。

## 后续：媒体控制器跟随当前标签

- 浏览网页时，管理页从当前 WebView 读取标题/地址，不再一直显示入口频道（例如果汁导航）；接收端投屏状态也覆盖为当前网页信息。原生嗅探播放器显示期间不覆盖其媒体信息。
- 嗅探列表按标签和文档代次隔离。切回仍保留的 WebView 恢复该页列表；新导航/刷新建立新代次并清空旧列表。缓存最多 31 个后台标签，每页最多 30 条，探测队列只处理当前页。
- 资源选择携带页面身份，即使两个标签出现同一媒体 URL，也拒绝旧列表按钮发来的跨页请求。资源回调仍校验 WebView、客户端和导航代次。
- 同名标签的预览图使用独立页面缓存键；新页尚未就绪时，迟到的旧截图不再显示。
- arm32 / arm64 debug 构建及 9 个 Node 测试文件通过（管理页 54 个场景）。Android 9 模拟器 BrowserMediaStateInstrumentation 通过真实本地网页切换、资源隔离/恢复、旧回调和旧点击拒绝、接收端状态覆盖以及原生播放器信息保留测试；资源发现事件由测试确定性注入，不代表已对果汁导航站点做在线测试。

## 性能与冗余清理

- 嗅探资源 JSON 改为只读快照；新增资源、探测结果完成、切页或清空时失效，未变化的状态轮询复用对象，减少主线程 JSON 分配及 GC 压力。
- 去重集合和主线程待处理资源通知都限制到当前文档 30 条；在提交 UI 回调前去重，避免大量重复 manifest 或不同媒体 URL 堆积回调。预约及导航清空使用同一锁，回调继续校验导航代次。
- 媒体控制区的固定 DOM 只在首次显示/错误恢复时构建；音轨选项独立缓存，选择变化只更新 value。移除把标题、准备状态、轨道选择和整页重建绑定的 mediaTrackKey 逻辑。
- HLS 探测正则预编译复用，HEAD 与 manifest 请求共用超时/请求头配置，减少重复代码。
- 验证：arm32/arm64 debug 构建、9 个 Node 测试文件（管理页 55 场景）通过。Android 9 回归涵盖 1,000 个资源事件限制到 30 条、快照不被后续变更修改、清空失效、10,000 次缓存读取复用同一实例（约 2 ms，含反射，仅为模拟器局部测量）。
- Playwright/Chromium 使用本地页面和模拟状态，连续 100 次标题/准备状态/轨道选择变化后，播放按钮、音量/进度 input、轨道 option 节点身份保持不变；编辑期间焦点及音量/进度值保留。未做整页加载基准或旧安卓真机功耗测试。
